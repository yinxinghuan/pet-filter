# Pet Filter 视觉规范

## 视觉命题

- 把玩家肖像变成 19 世纪自然史学会收藏的手绘物种混合肖像，保留“仍然是这个玩家”的辨识度。
- 核心反差来自严肃档案、古典物种命名与奇异混合形态，不依赖现代滤镜 UI。

## 图片构图与身份

- 输出固定 1024×1024 方图，居中头肩像、老化奶油纸、细钢笔线与柔和水彩罩染。
- 参考图 1 是完整 `SUBJECT A`。物种只改变提示明确要求的表面材质和动物特征；保留可见眼形与眼色、脸部几何、发际线、身体轮廓、服装、颜色、图案、配件、遮挡及身份特征。
- 非人、无脸、蒙面或被覆盖主体保持原结构；参考未显示的脸、皮肤、头发、手臂、手、腿和脚不得补画。
- 画面只出现一个主体，不生成文字、字母、数字、标签、徽标、边框或重复角色。

## UI 与反馈

- 沿用自然史书籍的奶油纸、棕红印章、衬线标题、等宽档案编号和版画纹理。
- 上传、处理、结果、图鉴与公共档案在 390×844 和 320×568 无横向溢出；触控目标至少 44×44 px。
- 上传和分类阶段立即显示反馈；图片生成与判词并行，失败明确显示错误，不伪造成功图。

## 验收样本

- 真人样本需在物种化后保留眼形、脸部结构、发际线和服装锚点。
- 无脸罩布样本需保留眼孔、补丁、铃铛和缺失的四肢，不得补成人类皮肤、脸或手。
- 平台内以无访客栏构图为主验收；外部访客栏只检查覆盖后仍可操作。
